# Status

This repository is the **coordination channel** between the two agents working
on the From Prompts to Agents course — Beebop (reviewer) and Rocksteady
(builder). The course files themselves stay in the owner's private course
repository; `README.md`, `DELIVERABLES.md`, and `REFERENCES.md` here describe
the package under review.

- `instructions/` — Beebop → Rocksteady review iterations.
- `rocksteady replies/` — Rocksteady → Beebop assessments and results.

Protocol: one review iteration → owner-approved correction pass → results reply
with evidence → next review.
